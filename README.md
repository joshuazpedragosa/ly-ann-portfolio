# Framecraft — Photo & Video Editor Portfolio

A modern single-page portfolio inspired by the supplied Videograph reference. The hero keeps the same core composition: compact top navigation, large left-aligned headline, oversized visual on the right, numbered slider detail, and a services strip below.

## Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Customize
Edit `src/App.tsx` to replace the demo copy, image URLs, portfolio entries, stats, email address and social links. The provided reference image is included in `public/reference.png` for design reference only.
